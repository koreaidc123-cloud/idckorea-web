# PC 세팅 순서

**컴퓨터 한 대에 3분이면 끝납니다.**

---

## 1. 애니데스크 설치하고 비밀번호 정하기

지금까지 하시던 그대로 하시면 됩니다.

**비밀번호를 정하셨으면 그 비밀번호를 기억해 두세요.** 다음 단계에서 한 번 칩니다.

---

## 2. USB 를 꽂고 `PC등록` 을 두 번 누르기

USB 안에 이 파일이 있습니다.

```
  PC등록
```

두 번 누르면 **"이 앱이 변경할 수 있도록 허용하시겠어요?"** 라고 물어봅니다.
→ **[예]** 를 눌러 주세요.

---

## 3. 창이 뜨면 두 가지만

### ① 어느 서버실인지 누르기

```
   ┌────────┐  ┌────────┐  ┌────────┐
   │  금촌  │  │ 영태리 │  │ 등원리 │
   └────────┘  └────────┘  └────────┘
```

지금 계신 곳을 누르세요. 누르면 **파랗게** 바뀝니다.

### ② 애니데스크 비밀번호 치기

1번에서 정하신 그 비밀번호를 칩니다.

### ③ 빨간 **[등록하기]** 버튼 누르기

---

## 4. 큰 숫자가 나오면 끝

```
        등록 완료

        Y-042

   이 컴퓨터의 품번입니다.
   랙에 붙이는 이름표에 이대로 적어 주세요.
```

**화면에 나온 그 번호를 이름표에 적어서 컴퓨터에 붙여 주세요.**

번호는 프로그램이 알아서 순서대로 붙여 줍니다.
직접 정하지 않으셔도 되고, 겹칠 걱정도 없습니다.

끝나면 **[다음 컴퓨터 하기]** 를 누르고 다음 PC 로 가시면 됩니다.

---

## 잘 안 될 때

| 화면에 나오는 말 | 이렇게 하세요 |
|---|---|
| **애니데스크 번호를 찾지 못했습니다** | 애니데스크를 한 번 켜신 뒤 **[등록하기]** 를 다시 누르세요 |
| **먼저 서버실을 골라 주세요** | 위쪽 큰 버튼 세 개 중 하나를 누르세요 |
| **등록하지 못했습니다** | 인터넷 선이 꽂혀 있는지 보시고, 그래도 안 되면 **화면을 사진 찍어 보내 주세요** |

**어떤 경우든 컴퓨터에 문제가 생기지는 않습니다.** 안 되면 사진 찍어 보내주시면 됩니다.

# 랙PC 등록 USB — 이 폴더가 최신입니다

**만든 날 : 2026-08-19**

이 폴더를 통째로 USB에 복사해서 쓰십니다.
바탕화면의 다른 `PC등록` 폴더들은 **8월 16일자 옛날 것**입니다. 쓰지 마세요.

---

## 왜 이 폴더를 새로 만들었나

8월 16일자 프로그램에는 **원격 재부팅 기능이 없습니다.**
그걸로 설치한 PC는 관리자에서 재부팅을 눌러도 아무 반응이 없습니다.
지금 랙에 설치된 14대가 전부 여기에 해당합니다.

이 폴더의 프로그램에는 두 가지가 들어 있습니다.

| | 내용 |
|---|---|
| **원격 재부팅** | 관리자에서 누르면 최대 2분 안에 재부팅됩니다 |
| **자동 갱신** | 하루 한 번 스스로 최신을 확인합니다 |

**자동 갱신이 핵심입니다.** 앞으로 프로그램이 바뀌어도
랙PC를 한 대씩 찾아다닐 필요가 없습니다. 이번이 마지막입니다.

---

## 파일 설명

| 파일 | 언제 씁니까 |
|---|---|
| **PC등록.bat** | 포맷한 새 PC를 처음 등록할 때 |
| **프로그램갱신.bat** | 이미 등록된 PC의 프로그램만 바꿀 때 |
| `kvc-agent.ps1` | 랙PC에서 2분마다 도는 프로그램 |
| `kvc-setup.ps1` | 등록 절차 |
| `kvc-update.ps1` | 갱신 절차 |
| `kvc-config.json` | **서버 주소와 등록 암호 (외부 유출 금지)** |

---

## ① 새 PC를 등록할 때

1. 포맷하고 윈도우 설치를 마칩니다
2. USB를 꽂고 **`PC등록.bat`** 을 **오른쪽 클릭 → 관리자 권한으로 실행**
3. 랙 · 층 · 자리를 적습니다 (예: 5 · 4 · 14)
4. 끝나면 관리자 화면 [미등록 PC] 에 올라옵니다

> **자리 번호는 오른쪽 끝이 1번입니다.**
> 서버실별 랙 수 — 금촌 7 · 영태리 9 · 등원리 6 (모두 4층 · 한 층 14자리)
> 범위를 벗어나면 서버가 거절합니다.

---

## ② 이미 설치된 PC를 갱신할 때 (14대)

애니데스크로 접속해서 **`프로그램갱신.bat`** 을 관리자 권한으로 실행하면 됩니다.

USB를 못 꽂는 상황이면, 그 PC의 **PowerShell(관리자)** 에서 아래 두 줄을 붙여넣으셔도 같습니다.

```powershell
iwr "https://idckorea-dusky.vercel.app/agent/kvc-agent.ps1" -OutFile "C:\KVC\kvc-agent.ps1" -UseBasicParsing
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-agent.ps1 -Once
```

두 번째 줄에서 `보냈습니다 - Y-006` 처럼 초록 글씨가 나오면 성공입니다.

**품번과 열쇠는 `C:\KVC\pc.json` 에 그대로 있습니다. 다시 등록하지 않습니다.**

### 갱신이 필요한 PC인지 먼저 확인하려면

```powershell
Select-String -Path C:\KVC\kvc-agent.ps1 -Pattern "CMD:" -Quiet
```

- `False` → 갱신 필요
- `True` → 이미 최신, 그냥 두시면 됩니다

## ③ 재부팅이 안 될 때 확인 순서

1. **Supabase에서 `06-B-사라진PC-잡기.sql` 을 돌리셨습니까**
   이걸 안 하면 서버가 명령을 전달하지 못합니다. 프로그램이 최신이어도 안 됩니다.
2. 그 PC의 프로그램이 최신입니까 (위 `Select-String` 확인)
3. 그 PC가 신호를 보내고 있습니까 (관리자 화면에서 초록불인지)

셋 다 맞으면 최대 2분 안에 재부팅됩니다.

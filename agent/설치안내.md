# 랙PC 하트비트 설치 안내

현장에서 세팅하시는 분이 보시는 문서입니다.

---

## 전체 그림

```
 랙PC 1,200대                          데이터베이스              관리자 랙맵
 ┌──────────────┐                    ┌────────────┐         ┌──────────┐
 │ kvc-agent.ps1 │──2분마다 직접──▶  │  Supabase  │────────▶│ 30초마다  │
 │  (자기 상태)   │   자기 한 줄만      │            │         │  자동 갱신 │
 └──────────────┘                    └────────────┘         └──────────┘
```

**중계기는 없습니다.** 각 PC 가 데이터베이스에 직접 씁니다.

**안전한 이유** — PC 한 대마다 전용 열쇠(토큰)를 줍니다.
그 열쇠로는 **자기 한 줄만** 고칠 수 있습니다.
남의 PC 도, 고객 정보도, 주문도 볼 수 없습니다.
열쇠가 새어나가도 그 PC 한 대만 영향입니다.

---

## 준비물

| | |
|---|---|
| 파일 | `kvc-agent.ps1` (USB 하나에 넣어 다니시면 편합니다) |
| 현장 등록 암호 | 대표님께 받으세요. 모든 서버실 공용입니다 |

## PC 한 대 설치 — 1분

PC 세팅을 마치고 애니데스크까지 깔았으면 마지막에 이것만 하면 됩니다.

1. `kvc-agent.ps1` 을 `C:\KVC\` 에 복사합니다.
2. **관리자 권한** PowerShell 을 열고:

```powershell
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-agent.ps1 -Setup
```

3. 두 가지만 물어봅니다.

| 묻는 것 | 넣는 값 | 예 |
|---|---|---|
| 품번 | 그 자리의 품번 | `Y-042` |
| 현장 등록 암호 | 대표님께 받은 암호 | `kvc-setup-…` |

4. 이런 화면이 나오면 성공입니다.

```
  사양을 읽는 중...
    CPU      : AMD Ryzen 7 3700X 8-Core Processor
    메모리   : 32GB
    저장장치 : 476GB
    그래픽   : NVIDIA GeForce GTX 1060 6GB
    애니데스크: 1042887613

  등록 완료 - Y-042
  잠시 뒤 관리자 화면 [미등록 PC] 에 이 컴퓨터가 나타납니다.
```

5. **2분 뒤 관리자 화면 → 미등록 PC** 에 이 컴퓨터가 뜹니다.
   사양·애니데스크 번호는 프로그램이 알아서 읽어옵니다. 손으로 적을 필요 없습니다.
   관리자 화면에서 **자리(랙·층·번호)만 지정**하시면 랙맵에 나타납니다.

> **애니데스크 비밀번호는 이 프로그램이 다루지 않습니다.**
> 비밀번호는 관리자 화면에서만 등록하고, 거기서만 열람 기록이 남습니다.

## 잘 되는지 확인하기

```powershell
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-agent.ps1 -Once
```

`보냈습니다 - Y-042 (사용중: 아니오)` 가 나오면 정상입니다.

기록은 여기 쌓입니다 → `C:\KVC\agent.log`

## 안 될 때

| 화면에 나오는 말 | 원인과 해결 |
|---|---|
| `현장 등록 암호가 맞지 않습니다` | 암호 오타. 대표님께 다시 확인 |
| `품번 형식은 K-001…` | `Y42` 처럼 쓰셨습니다. `Y-042` 형태여야 합니다 |
| `거절됨 : DENIED` | 이 PC 의 열쇠가 만료됐거나 품번이 바뀌었습니다. `-Setup` 으로 다시 등록 |
| `전송 실패` | 이 PC 가 인터넷에 못 나갑니다. 랜선·공유기 확인 |
| 관리자 화면에 안 뜸 | `-Once` 를 돌려보세요. 여기서 성공이면 관리자 화면을 새로고침 |
| 애니데스크 번호가 빈칸 | 애니데스크를 아직 한 번도 실행하지 않았습니다. 한 번 켜고 다시 `-Setup` |
| 껐는데도 온라인으로 보임 | 3분 지나면 자동으로 다운으로 바뀝니다 |

## 기존 1,200대는 어떻게 하나

한 번에 다 설치할 필요 없습니다. **점진 전환**입니다.

1. **지금** — 관리자 화면에서 품번·위치·애니데스크 정보를 손으로 등록해 둡니다.
   랙맵은 그 정보로 그려집니다. (지금까지 하시던 방식 그대로)
2. **앞으로** — 새로 세팅하거나 고쳐서 다시 넣는 PC 부터 에이전트를 깝니다.
   그 PC 는 그때부터 상태가 자동으로 올라옵니다.
3. 시간이 지나면서 자동으로 잡히는 PC 가 늘어납니다.
   관리자 화면은 두 가지를 섞어서 잘 보여줍니다.

---

## PC 를 뺄 때

랙에서 PC 를 빼거나 폐기하실 때:

```powershell
Unregister-ScheduledTask -TaskName 'KVC-Agent' -Confirm:$false
Remove-Item C:\KVC -Recurse -Force
```

관리자 화면에서 그 품번을 삭제하시면 열쇠도 함께 사라집니다.

# 랙PC 하트비트 설치 안내

현장에서 세팅하시는 분이 보시는 문서입니다.

---

## 전체 그림

```
 랙PC 1,200대                서버실 중계기 1대            홈페이지 서버
 ┌──────────┐              ┌──────────────┐         ┌─────────────┐
 │ kvc-agent │──1분마다──▶  │  공유폴더     │         │             │
 │  .ps1     │   파일 1개    │  kvc-beat    │         │ /api/       │
 └──────────┘              │              │──1분──▶ │  heartbeat  │
 ┌──────────┐              │ kvc-relay.ps1│  달라진   │      ↓      │
 │ kvc-agent │──────────▶   │  가 모아서    │  것만    │   데이터베이스 │
 └──────────┘              └──────────────┘         │      ↓      │
   … 1,200대                                        │  관리자 랙맵  │
                                                    └─────────────┘
```

**왜 중계기를 두나** — 1,200대가 각자 인터넷으로 쏘면 하루 172만 건입니다.
중계기가 모아서 달라진 것만 올리면 하루 수천 건으로 줄고,
랙PC는 내부망 밖으로 나갈 필요가 없어 훨씬 안전합니다.

---

## 1단계 · 서버실 중계기 (서버실마다 딱 한 대)

관리자가 늘 쓰시는, 항상 켜져 있는 PC 한 대를 고릅니다.

1. `kvc-relay.ps1` 을 그 PC 의 `C:\KVC\` 에 복사합니다.
2. **관리자 권한** PowerShell 을 열고:

```powershell
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-relay.ps1 -Setup
```

3. 물어보는 대로 넣습니다.

| 묻는 것 | 넣는 값 | 예 |
|---|---|---|
| 서버실 기호 | K / Y / D | `Y` |
| 상태 파일 폴더 | 아무 빈 폴더 | `C:\kvc-beat` |
| 서버 주소 | 홈페이지 주소 | `https://idckorea-dusky.vercel.app` |
| 중계기 암호 | Vercel 의 `KVC_RELAY_KEY` 와 **같은 값** | (대표님께 받으세요) |

4. 끝나면 화면에 **`\\컴퓨터이름\kvc-beat`** 가 나옵니다. **이 주소를 적어두세요.**
   다음 단계에서 랙PC마다 이 주소를 넣습니다.

---

## 2단계 · 랙PC (한 대씩)

PC 세팅을 마치고 애니데스크까지 깔았으면 마지막에 이것만 하면 됩니다.

1. `kvc-agent.ps1` 을 `C:\KVC\` 에 복사합니다.
   (USB 하나에 넣어 다니시면 편합니다)
2. **관리자 권한** PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-agent.ps1 -Setup
```

3. 두 가지만 넣습니다.

| 묻는 것 | 넣는 값 | 예 |
|---|---|---|
| 품번 | 그 자리의 품번 | `Y-042` |
| 중계기 공유폴더 | 1단계에서 적어둔 주소 | `\\RELAY-Y\kvc-beat` |

4. **1분 뒤 관리자 화면 → 미등록 PC** 에 이 컴퓨터가 뜹니다.
   사양·애니데스크 번호는 프로그램이 알아서 읽어옵니다. 손으로 적을 필요 없습니다.

> **애니데스크 비밀번호는 이 프로그램이 다루지 않습니다.**
> 비밀번호는 관리자 화면에서만 등록하고, 거기서만 열람 기록이 남습니다.

---

## 잘 되는지 확인하기

랙PC 에서:
```powershell
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-agent.ps1 -Once
```
→ `보냈습니다 -> \\RELAY-Y\kvc-beat\Y-042.json` 이 나오면 정상입니다.

중계기에서:
```powershell
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-relay.ps1 -Once
```
→ `14:03:11  변경분 3대 전송  저장 3  미등록 1` 처럼 나오면 정상입니다.

## 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| `그 폴더에 접근할 수 없습니다` | 중계기 공유폴더 권한. 중계기에서 폴더 → 속성 → 공유 → Everyone 읽기/쓰기 |
| 관리자 화면에 안 뜸 | 중계기에서 `-Once` 를 돌려보세요. `전송 실패` 가 나오면 서버 주소나 암호가 틀린 것입니다 |
| 사양이 `사양 미확인` | 그 PC 에서 `-Once` 를 돌려 어떤 값이 나오는지 확인 |
| 애니데스크 번호가 빈칸 | 애니데스크를 아직 한 번도 실행하지 않은 상태입니다. 한 번 켜고 1분 기다리세요 |
| 껐는데도 온라인으로 보임 | 3분 지나면 자동으로 다운으로 바뀝니다 (설정에서 조절 가능) |

## 기존 1,200대는 어떻게 하나

한 번에 다 설치할 필요 없습니다. **점진 전환**입니다.

1. **지금** — 관리자 화면에서 품번·위치·애니데스크 정보를 손으로 등록해 둡니다.
   랙맵은 그 정보로 그려집니다. (지금까지 하시던 방식 그대로)
2. **앞으로** — 새로 세팅하거나 고쳐서 다시 넣는 PC 부터 에이전트를 깝니다.
   그 PC 는 그때부터 상태가 자동으로 올라옵니다.
3. 시간이 지나면서 자동으로 잡히는 PC 가 늘어납니다.
   관리자 화면은 두 가지를 섞어서 잘 보여줍니다.

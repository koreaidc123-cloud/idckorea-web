# 랙PC 하트비트 — 준비와 설치

대표님이 보시는 문서입니다.
현장에서 세팅하시는 분께는 **[현장-작업순서.md](현장-작업순서.md)** 를 인쇄해서 드리세요.

---

## 전체 그림

```
 랙PC 1,200대                          데이터베이스              관리자 랙맵
 ┌──────────────┐                    ┌────────────┐         ┌──────────┐
 │ kvc-agent.ps1 │──2분마다 직접──▶  │  Supabase  │────────▶│ 30초마다  │
 │  (자기 상태)   │   자기 한 줄만      │            │         │  자동 갱신 │
 └──────────────┘                    └────────────┘         └──────────┘
```

**중계기는 없습니다.** 각 PC 가 데이터베이스에 직접 씁니다.

PC 한 대마다 **전용 열쇠(토큰)** 를 줍니다. 그 열쇠로는 **자기 한 줄만** 고칠 수 있습니다.
남의 PC 도, 고객 정보도, 주문도 못 봅니다. 열쇠가 새어나가도 그 PC 한 대뿐입니다.

## 대표님 준비 — USB 하나 만들기 (한 번만)

USB 하나에 **이 폴더의 파일 4개**를 통째로 넣으시면 됩니다.

```
USB/
  PC등록.bat        ← 세팅하시는 분이 두 번 누를 파일
  kvc-setup.ps1     ← 등록 화면
  kvc-agent.ps1     ← 하트비트 프로그램
  kvc-config.json   ← ★ 여기만 채우시면 됩니다
```

`kvc-config.json` 을 메모장으로 열어서 두 줄을 채웁니다.

```json
{
  "server": "https://idckorea-dusky.vercel.app",
  "setupKey": "여기에 Vercel 의 KVC_SETUP_KEY 와 같은 값"
}
```

> USB 를 여러 개 만드셔도 되고, 하나를 돌려쓰셔도 됩니다.
>
> **보안**: 이 USB 에 든 암호로 할 수 있는 일은 "새 PC 를 미등록 상태로 올리는 것" 뿐입니다.
> 고객 정보도, 주문도, 다른 PC 도 볼 수 없습니다. USB 를 잃어버리면
> Vercel 에서 `KVC_SETUP_KEY` 값만 바꾸시면 그 USB 는 바로 무효가 됩니다.

## 현장에서 (세팅하시는 분)

**컴퓨터 한 대에 3분.** 자세한 건 [현장-작업순서.md](현장-작업순서.md) 에 있습니다.

1. 애니데스크 설치 + 비밀번호 설정 (지금까지 하시던 그대로)
2. USB 꽂고 **PC등록** 두 번 누르기 → 관리자 권한 [예]
3. 서버실 버튼 누르기 → 애니데스크 비밀번호 치기 → **[등록하기]**
4. 큰 글씨로 나온 품번(`Y-042`)을 이름표에 적어 붙이기

**품번은 서버가 알아서 순서대로 붙입니다.** `Y-001` 다음은 `Y-002` 입니다.
겹치지 않고, 세팅하시는 분이 번호를 관리할 필요가 없습니다.

같은 컴퓨터를 다시 등록하면 **원래 품번을 그대로** 씁니다 (메인보드 번호로 알아봅니다).
새 번호를 낭비하지 않습니다.

## 등록 후 대표님이 하실 일

관리자 화면 **[미등록 PC]** 에 새 컴퓨터가 뜹니다.

거기서 **자리(랙 · 층 · 번호)만 지정**하시면 랙맵에 나타나고, 판매 재고로 올라갑니다.
사양 · 애니데스크 번호 · 비밀번호는 이미 채워져 있습니다.

---

## 기술자용 (필요할 때만)

명령줄로 등록하실 수도 있습니다. 품번을 직접 지정하고 싶을 때 씁니다.

```powershell
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-agent.ps1 -Setup
```

지금 잘 보내지는지 확인:

```powershell
powershell -ExecutionPolicy Bypass -File C:\KVC\kvc-agent.ps1 -Once
```

기록: `C:\KVC\agent.log`

| 증상 | 원인과 해결 |
|---|---|
| `거절됨 : DENIED` | 열쇠가 맞지 않습니다. USB 로 다시 등록 |
| `전송 실패` | 인터넷 연결 확인 |
| 껐는데도 온라인 | 3분 지나면 자동으로 다운으로 바뀝니다 |

## 기존 1,200대는 어떻게 하나

한 번에 다 할 필요 없습니다. **점진 전환**입니다.

1. **지금** — 관리자 화면에서 품번 · 위치 · 애니데스크 정보를 손으로 등록해 둡니다 (지금까지 하시던 방식)
2. **앞으로** — 새로 세팅하거나 고쳐서 다시 넣는 PC 부터 USB 로 등록합니다
3. 시간이 지나면서 자동으로 잡히는 PC 가 늘어납니다. 관리자 화면은 두 가지를 섞어서 보여줍니다

## PC 를 뺄 때

```powershell
Unregister-ScheduledTask -TaskName 'KVC-Agent' -Confirm:$false
Remove-Item C:\KVC -Recurse -Force
```

관리자 화면에서 그 품번을 삭제하시면 열쇠도 함께 사라집니다.

🔎 대장에서 사라진 PC (노란 상자)

  • 마지막 신호 칸을 보세요
  • 신호 오는 중 · ○초 전 (빨강) → 지금 살아있는 PC
  • ○분 전 · 멈춤 → 이미 다시 등록된 옛 기록. 지워도 됩니다
  • 살릴 때는 애니데스크 번호 [복사] → 그 번호로 원격 접속 → PC등록 다시 실행
🗑으로 지우면 숨김 목록에 들어가서, 그 PC가 계속 신호를 보내도 다시 안 나타납니다.
되돌리려면 화면 위쪽 다시 보이기를 누르세요.

3. 🔍 검증 대기

품번은 받았지만 아직 못 파는 PC들입니다. ← 여기 숫자가 있으면 그만큼 돈을 못 벌고 있는 겁니다.

  1. 비밀번호 [보기] 를 눌러 애니데스크 비밀번호를 확인
  2. 다른 PC에서 실제로 애니데스크 접속 해봅니다
  3. 잘 되면 → 접속 확인 완료 → 판매 → 즉시 고객 화면에 뜹니다
  4. 안 되면 → 접속 실패 → 점검
비밀번호를 볼 때마다 누가 언제 봤는지 기록이 남습니다. 정상입니다.

9. 🔔 알림 발송

만료가 다가온 고객 목록입니다. 품번 · 회원 · 연락처 · 가입 · 만료일.

지금은 실제 발송이 안 됩니다. 문자 서비스(알리고) 연동 전이라 안내창만 뜹니다.
연동되면 알림톡이 먼저 가고, 실패하면 문자로 자동 전환됩니다.
그때까지는 이 목록을 보고 직접 전화하시면 됩니다.

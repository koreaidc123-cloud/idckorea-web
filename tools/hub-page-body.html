AI 도구 가이드

원격PC 에서 AI 돌리기

처음 하시는 분도 따라 할 수 있게 순서대로 적었습니다. 설치 방법은 바뀔 수 있으니 각 도구의 공식 안내를 함께 확인해 주세요.

1

클로드 코드 24시간 돌리기

원격PC 에서 클로드 코드를 켜 두면 노트북을 덮어도 작업이 원격PC 에서 이어집니다.

순서 보기
  1. 애니데스크로 원격PC 에 접속합니다.
  2. Node.js(LTS)와 Git for Windows 를 설치합니다.
  3. PowerShell 을 열고 npm install -g @anthropic-ai/claude-code 를 입력합니다.
  4. 작업 폴더로 이동해 claude 를 입력하고, 처음 한 번 로그인합니다 (Claude 유료 요금제 또는 Anthropic API 결제 필요).
  5. 윈도우 절전 모드를 끄고 애니데스크 창을 닫습니다. 원격PC 는 켜져 있으므로 작업이 계속됩니다.

공식 안내: docs.anthropic.com (Claude Code)

2

코덱스 시작하기

OpenAI 의 코딩 도구 코덱스(Codex CLI)를 원격PC 에 설치해 쓰는 순서입니다.

순서 보기
  1. 원격PC 에 Node.js(LTS)를 설치합니다.
  2. PowerShell 에서 npm install -g @openai/codex 를 입력합니다.
  3. 작업 폴더에서 codex 를 입력하고 ChatGPT 계정 또는 API 키로 로그인합니다.
  4. 윈도우에서 쓰는 방법(WSL 권장 여부 등)은 자주 바뀌므로 공식 안내를 먼저 확인합니다.

공식 안내: github.com/openai/codex

3

휴대폰으로 원격 확인

밖에서도 휴대폰으로 원격PC 화면을 열어 AI 가 일을 잘하고 있는지 볼 수 있습니다.

순서 보기
  1. 휴대폰 앱 스토어에서 AnyDesk 앱을 설치합니다.
  2. 내 가상컴 화면에서 내 PC 의 애니데스크 번호와 접속 비밀번호를 확인합니다.
  3. 앱에 번호를 넣고 접속합니다. 확인이 끝나면 연결만 끊습니다 (PC 를 끄지 마세요).
  4. 영상이 오가므로 가능하면 와이파이에서 접속합니다.
4

원격PC AI 세팅 체크리스트

AI 를 오래 돌리기 전에 한 번만 확인해 두면 중간에 멈추는 일을 줄일 수 있습니다.

체크리스트 보기
  • 전원 옵션 → 절전 모드 안 함, 화면 끄기만 켜 두기
  • 윈도우 업데이트 → 사용 시간을 작업 시간에 맞춰 자동 재시작 피하기
  • Node.js · Git · Python 등 필요한 도구 설치 확인
  • 작업 폴더는 깃허브나 클라우드에 따로 백업
  • AI 가 남기는 기록(로그)을 파일로 저장하게 설정
  • 남은 기간 확인 — 끝나는 날이 가까우면 미리 연장
5

보안 수칙

AI 도구는 내 계정으로 움직입니다. 아래 다섯 가지만 지켜도 사고를 크게 줄일 수 있습니다.

수칙 보기
  • API 키·비밀번호를 프롬프트나 코드에 붙여넣지 않기 (환경변수에 보관)
  • 애니데스크 접속 비밀번호를 다른 사람과 공유하지 않기
  • 출처를 모르는 스크립트·프로그램은 실행하지 않기
  • 삭제·결제·발송처럼 되돌릴 수 없는 작업은 AI 가 하기 전에 직접 확인하기
  • 쓰지 않는 계정은 원격PC 브라우저에서 로그아웃
